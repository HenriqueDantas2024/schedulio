# Priorização MoSCoW — Grade Horária IMP

## 📦 MUST HAVE (Primeira Versão)
- [ ] Cadastro de professores (nome, email, matérias)
- [ ] Cadastro de turmas (concurso, local, turno M/T/N)
- [ ] Montagem da grade horária semanal pelo coordenador
- [ ] Geração automática das tirinhas por professor
- [ ] Envio de email com um clique para os professores
- [ ] Relatório de horas por professor no mês

## 📦 SHOULD HAVE (Logo Depois)
- [ ] Portal do professor com login próprio
- [ ] Relatório de aulas por turma
- [ ] Exportar grade como PDF
- [ ] Histórico de grades de semanas anteriores

## 📦 COULD HAVE (Se Der Tempo)
- [ ] App mobile para professores
- [ ] Notificação automática quando grade é alterada
- [ ] Integração com calendário (Google Calendar)

## 📦 WON'T HAVE (Futuro)
- [ ] Gestão financeira / pagamento de professores
- [ ] Chat interno entre coordenadores e professores
